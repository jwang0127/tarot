# 月隐 Tarot

一个手机优先、同时适配桌面端的中文塔罗自我探索网站。纯静态实现，无需构建即可打开 `index.html` 使用。

## 本地运行

无需安装依赖，直接用任意静态服务器打开：

```bash
# 方式一：直接双击 index.html
# 方式二：本地服务器
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 功能

- **问题占卜**：五种主题、示例问题、三种牌阵（单张指引 / 时间之流 / 两难对比），根据问题自动推荐牌阵
- **今日一牌**：每天固定一张牌，含关键词、今日提醒与今日行动；当天翻开后保持已翻开状态
- **牌意图鉴**：78 张牌全部拥有独立的正位 / 逆位牌意，支持搜索与按花色筛选
- **手绘风牌面图案**：78 张牌均有内联 SVG 线稿牌面（大阿卡纳每张独立图案，小阿卡纳按传统点数布局），逆位时图案倒转，无需加载任何图片资源
- 78 张牌随机抽取不重复，正位 / 逆位（约 30% 逆位），使用 `crypto.getRandomValues` 洗牌
- 发牌、翻牌动画，尊重系统"减弱动态效果"设置
- 复制解读结果，方便保存或分享
- 可开关的轻量合成音效（偏好会记住）
- 基于 hash 的路由，手机返回键可正常回退
- 不保存用户问题或历史牌局，仅在本机记录"今日一牌是否已翻开"与音效偏好

## 部署说明

本项目适合 GitHub Pages 静态部署。DeepSeek API Key 不能放进前端代码；GitHub Secrets 只能供 GitHub Actions 构建时使用，不能让公开网页安全地在浏览器中调用 DeepSeek。后续 AI 功能需要一个服务端代理或其他安全后端。
